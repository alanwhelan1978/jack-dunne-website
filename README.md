# Jack Dunne Menswear Website

Website for **Jack Dunne Menswear**, an independent menswear retailer based at 79 Main Street, Gorey, Co. Wexford, Ireland.

Established in 1993, Jack Dunne Menswear specialises in contemporary menswear, men's suits, wedding suits and formal hire, with an emphasis on personal service and expert fitting.

## Project Overview

The website has been designed as a modern brochure and lead-generation website rather than a traditional e-commerce store.

Its main objectives are to:

- Showcase Jack Dunne Menswear and its brands
- Promote men's suits and contemporary menswear
- Generate wedding and formal hire enquiries
- Promote occasion wear
- Provide store information and opening hours
- Sell digital gift vouchers
- Improve local search visibility in Gorey and Co. Wexford
